# 🌐 Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my education, projects, achievements, and contact information.

## 📌 Features

- Clean and modern UI
- Fixed navigation bar
- Full-screen sections
- Hero section with social links
- About, Qualifications, Projects, Achievements, and Contact sections
- Contact form
- Responsive design for mobile devices
- Smooth section navigation using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
